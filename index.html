抽籤規則

  1. 一般日：船長從公會成員池抽 1 人；守護天使從高戰池抽 1 人；船艙 4 從公會成員池抽 5 人，並排除當日船長與守護天使。
  2. 三個池子獨立：船長池、守護天使池、船艙 4 池互不影響，各自抽完才重複。
  3. 特別日：如果船長抽到高戰名單中的人，守護天使固定為會長，船艙 4 自動塞入剩餘 5 位高戰；當天只扣船長池，其餘池子不扣。
  4. 同日覆蓋：同一日期已有紀錄時，再抽會詢問是否覆蓋；覆蓋前會先把原本當天扣掉的人補回池子。

危險操作

這些操作會直接改 Firebase 雲端資料，所有人都會看到變更。

Firebase 必填設定

你目前提供的 Firebase Web App 設定還缺 databaseURL。請到 Firebase Console → Build → Realtime Database → 建立資料庫後，把資料庫網址貼進程式中的 databaseURL。

網址通常長得像：

https://guild-draw-default-rtdb.asia-southeast1.firebasedatabase.app/

然後把程式上方這行：

databaseURL: "https://capydraw-7f7de-default-rtdb.asia-southeast1.firebasedatabase.app/",

改成：

databaseURL: "你的 Realtime Database 網址",
雲端版工具：建議部署到 GitHub Pages，對方手機直接開網址即可共用同一份資料。
